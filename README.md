# awesome-list

**读过，再留下。**

这里是 [DGOR1337](https://github.com/DGOR1337) 的个人阅读清单，记录读过的文章、论文、文档、书籍和其他值得留下的内容，以及自己的理解与笔记。

不追求收集数量，只保留真实阅读后的收获。**收藏不等于读过，读过不等于掌握。**

[阅读清单](#2026) · [个人笔记](notes/README.md) · [添加方法](CONTRIBUTING.md) · [笔记模板](templates/reading-note.md)

## 收录方式

- 按**实际阅读年份**归档，新年份放在前面；同一年内按主题分类，新条目放在对应主题顶部。
- 每条记录保留原文链接、阅读日期和一句自己的理解；需要展开时，再链接个人笔记。
- 状态按实际情况标注：`已读`、`精读`、`已复现`；尚未读完的内容不放进正式清单。
- 链接到原作者的内容，不搬运文章全文。引用与自己的理解分开记录。
